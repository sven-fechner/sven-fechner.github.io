Masterarbeit

Integration von neuronalen Netzen in eine Desktopanwendung zur medizinischen Bildverarbeitung

In dieser Arbeit geht es darum herauszufinden, in wie fern sich neuronale Netze in Desktopanwendungen einbauen und benutzen lassen...

Abstract weiterlesen

Im spezifischen geht es hier darum, ein Video mit einem neuronalen Netz zu analysieren und Ergebnisse der Analyse wieder ausgeben zu lassen. Ziel ist es, so eine Anwendung in deutschen Arztpraxen benutzen zu können. Dafür wurde zuerst eine Marktanalyse durchgeführt, um herauszufinden, mithilfe welcher Werkzeuge man aktuell Desktopanwendungen schreibt. Die so entstandene Liste, welche die Anzahl an Nennungen berücksichtigt, wurde dann hinsichtlich der geeignetsten Programmiersprachen für das Machine Learning und die Integration eines neuronalen Netzes im PyTorch-Format gefiltert. Bei der Analyse, welche Betriebssysteme in deutschen Arztpraxen verwendet werden, offenbarte sich, dass hier Windows dominierend ist. Daher wurden die Werkzeuge ebenfalls dahingehend gefiltert, ob sie Anwendungen für Windows schreiben können. Es stellte sich heraus, dass PyTorch von sich aus C++, Python und Java unterstützt. Um den zeitlichen Rahmen der Arbeit zu beachten wurden insgesamt drei Werkzeuge ausgewählt, je eins pro eben genannter Programmiersprache. Namentlich sind das UWP, PyQt6 und JavaFX. In Folge war ich aber nur mit PyQt6 in der Lage ein vollständig funktionierende und den Wünschen entsprechende Anwendung zu schreiben. In JavaFX gab es Probleme aufgrund des Multithreadings und generell mit der Auswertung der einzelnen Bilder. In UWP ließ sich die benötigte Bibliothek OpenCV nicht einbinden. Der Fehler könnte hier aber auch auf die von Microsoft empfohlene Entwicklungsumgebung zurückzuführen sein. Ergebnisse der Performanz konnte ich so nur für die Anwendung von PyQt6 und JavaFX sammeln. Dabei stellte sich heraus, dass die PyQt6-Anwendung sowohl schneller als auch ressourcensparender arbeitet als die JavaFX-Anwendung. Daraus schließend steht die Vermutung, dass Python im Allgemeinen besser für so ein Unterfangen geeignet zu sein scheint als Java.

Auszug mit Einleitung, Methodik, Implementierung und Fazit ansehen

Bachelorarbeit

Modellierung und Simulation zur COVID-19 Pandemie unter Verwendung von Open-Source-Software

Anhand der verwendeten Applikationen soll aufgezeigt werden, über welches Spektrum sich die Open Source Applikationen in Bezug auf COVID-19 erstrecken...

Abstract weiterlesen

Außerdem wird überprüft, welche Modelle den verschiedenen Applikationen als Grundlage dienen. Weiterhin soll herausgefunden werden, in wie weit die Applikationen Wert auf Benutzbarkeit und Übertragbarkeit legen, sprich Wert darauf legen, vom Nutzer und Entwickler einfach verstanden, angewendet und bearbeitet zu werden. Ebenfalls werden die Modelle und Simulationen, die von den Applikationen durchgeführt werden, validiert, verifiziert und evaluiert. Dadurch wird festgestellt, ob die Applikationen überhaupt gültig und glaubwürdig sind. Auch wird festgestellt, ob diese ihren Zweck erfüllen und welche Fragen durch die Modellierung und Simulation auftreten.
